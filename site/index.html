Features

A spec that lives in files, not one giant document.

Everything you need to author, assemble, and exercise an OpenAPI spec — from the comfort of your editor.

📁

Structured projects

Initialize a folder-friendly layout with separate directories for paths, schemas, and security schemes.

🚀

Mock server

Serve a mock REST / Web API from your spec so clients can develop against it before the backend exists.

OpenAPI 3.0

Authoring around the OpenAPI 3.0 standard, so the output drops straight into the tools you already use.

How it works

Three commands, start to mock.

Your spec stays split into small, reviewable files. OPM stitches them together and brings them to life.

opm init

Creates paths/, components/schemas/, and components/securitySchemes/ with example files to start from.

Author in files

Add a YAML file per path and per schema. Each piece of the API lives on its own, easy to diff and review.

opm build

Gathers info.yaml, every path, and every schema into a single generated openapi.yaml.

opm serve

Spins up a mock REST API from the built spec — default port 3000, configurable with --port.

Get started

Install once, scaffold in seconds.

Works with both npm and Bun. Install globally, then drive your project with three subcommands.

terminal 
# install globally (npm)
npm install -g opm
# …or with Bun
bun install -g opm

# 1. scaffold a new project
opm init petstore

# 2. build the final openapi.yaml
opm build

# 3. serve a mock API (defaults to port 3000)
opm serve --port 3000
